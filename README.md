🚀 How to Run the Project

1. Open Terminal
```bash
cd D:\shravanee-pawar-portfolio
```
 2. Install dependencies
```bash
npm install
```
 3. Start the project
```bash
npm run dev
```
4. Open in browser
Open the URL shown in the terminal, usually:
```text
http://localhost:5173
```
 5. Build for production
```bash
npm run build
```
 6. Preview production build
```bash
npm run preview
```
